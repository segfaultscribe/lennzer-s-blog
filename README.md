# Lennzer's Blog

A minimal personal tech blog built with [Astro](https://astro.build).

## Tech Stack
- **Framework**: [Astro](https://astro.build)
- **Styling**: Custom CSS with CSS Variables
- **Fonts**: Crimson Pro (body), Space Mono (navbar), JetBrains Mono (code)
- **Deployment**: Vercel

## Development
```bash
npm i
npm run dev
```

## Deploy

Deployed on [Vercel](https://vercel.com).
